Views (32) + materialized view

All 32 views were created by one migration (20260620600000_daily_diary_views.js). Only ref_district, ref_police_station (import module) and the matview mv_record_stats are referenced by code. The other ~30 — ref_* enums, fir/arrest/missing/uidb/pcr_kalandra_master typed-extraction views, and 21 rpt_NN_* per-report views — are a DEAD parallel implementation of the Daily Diary reports: the Node daily-diary module aggregates in memory and python_worker queries records directly. The *_master views remain useful as documentation of what's inside records.data per type.
